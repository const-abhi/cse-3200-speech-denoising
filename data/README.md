# Datasets

The datasets used in this project are downloaded separately from their
official/research distribution sources.

## VoiceBank-DEMAND
Used as the primary clean/noisy speech benchmark source.

## DEMAND
Used as a source of real-world environmental noise.

## ESC-50
Used as an additional source of environmental sound recordings.

Raw datasets are intentionally not stored in this repository.

See the project documentation for dataset acquisition and preprocessing
instructions.
